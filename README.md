# Calamity Boss Loadouts

Calamity addon for Dycel's Boss Loadouts.
Adds Calamity bosses and permanent buffs to the menus, alongside a toggle for the Odd Mushroom.

If you find any bug, or have a suggestion for a future update, submit them in the Discord server below.
